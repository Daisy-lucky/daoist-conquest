# 一、游戏概述

## 1.1 游戏名称
**《道境征途》**（英文名：Daoist Conquest）

## 1.2 游戏类型
单人回合制策略占城游戏（类似《占城大师》Risk 风格）

## 1.3 目标受众
- 喜爱策略战棋类游戏的玩家
- 对中国道教神话、传统文化感兴趣的玩家
- 年龄 16+，适合休闲与中度策略玩家

## 1.4 游戏平台
- PC（Windows / Mac / Linux）
- 可扩展至移动端（iOS / Android）

## 1.5 开发技术栈（规划）
- 引擎：Unity 或 Godot
- 语言：C# 或 GDScript
- 数据存储：JSON / SQLite

## 1.6 核心玩法规格
| 项目 | 说明 |
|------|------|
| 玩家数量 | 1人（对抗 AI） |
| 地图规模 | 28~36座城池 |
| AI对手 | 2~4个 AI 势力 |
| 单局时长 | 30~60分钟 |
| 回合制 | 异步回合，玩家操作完毕后点击"结束回合" |

## 1.7 游戏特色
- 🏯 **道教神话世界观** — 取材自道教经典、神仙体系、名山福地
- 🎯 **策略占城** — 调兵遣将、合纵连横、攻城略地
- 🧙 **法术法宝系统** — 独特的道教法术与法宝，改变战局
- 🐉 **神兽系统** — 召唤神兽助战，扭转乾坤
- 🤖 **智能AI** — 不同性格的 AI 对手，各有策略倾向

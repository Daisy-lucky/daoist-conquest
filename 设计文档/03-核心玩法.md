# 三、核心玩法

## 3.1 玩法概述

《道境征途》的核心玩法继承《占城大师》的经典占城策略框架，并融入道教神话特色系统。

**基本循环：**
```
开始回合 → 查看全局 → 调兵遣将 → 攻城/防守 → 使用法术 → 结束回合
```

## 3.2 回合流程

每个回合按以下阶段进行：

### 阶段一：回合开始（自动）
- 所有己方城池产出 **灵脉资源**
- 城池内兵力自动恢复少量（受灵脉等级影响）
- 触发随机事件（如有）
- 显示上回合战报

### 阶段二：战略部署
- 查看全局地图，分析敌我态势
- 选择要进攻或防守的城池
- 使用法术或法宝

### 阶段三：调兵遣将
- 从己方城池调兵（仙兵）到相邻己方城池
- 每座城池每回合可调出/调入兵力各一次
- 调兵数量受城池 **灵脉等级** 限制

### 阶段四：攻城指令
- 选择己方城池 → 选择相邻敌方城池 → 指定进攻兵力数量
- 可发动多路进攻（分别结算）
- 进攻方需至少留 1 兵守城

### 阶段五：战斗结算（自动）
- 进攻方与防守方自动进行战斗
- 按 3.4 战斗规则计算胜负
- 显示战斗结果动画

### 阶段六：法术阶段
- 可在战斗前/后使用法术
- 每回合可使用 1 次主动法术
- 法宝使用不受次数限制（但有冷却）

### 阶段七：回合结束
- 检查胜利条件
- 保存状态
- 轮到 AI 行动

## 3.3 地图与城池机制

### 城池基础属性

| 属性 | 说明 | 范围 |
|------|------|------|
| **兵力** | 当前驻守的仙兵数量 | 0~999 |
| **灵脉等级** | 决定资源产出和兵力上限 | Lv.1 ~ Lv.10 |
| **防御值** | 守城加成系数 | 1.0 ~ 3.0 |
| **灵脉产出** | 每回合产出的灵脉资源 | 依等级而定 |

### 城池类型

| 类型 | 特点 |
|------|------|
| **仙山福地** | 标准城池，均衡型 |
| **洞天秘境** | 灵脉产出高，防御较低 |
| **天关要塞** | 防御极高，产出较低 |
| **圣地灵脉** | 产出极高，战略要地（每个区域仅 1 座） |

### 兵力移动规则
- 兵力只能沿 **相邻路线** 移动（地图上城池之间有连线）
- 进攻时，兵力从出发城移动到目标城
- 不能跨城移动（必须逐城推进）
- 可通过 **传送阵**（特殊法术）实现远程调兵

## 3.4 战斗规则

### 基础战斗公式

```
进攻方战斗力 = 进攻兵力 × (1 + 将领加成 + 法术加成)
防守方战斗力 = 防守兵力 × (1 + 防御加成 + 城池防御系数 + 法术加成)
```

### 胜负判定
- 进攻方战斗力 > 防守方战斗力：进攻方胜利
- 进攻方战斗力 ≤ 防守方战斗力：进攻方失败

### 战后损失
- **进攻方胜利**：剩余兵力 = 进攻兵力 × (0.3 ~ 0.7)（随机浮动），占领城池
- **进攻方失败**：进攻兵力归零，防守方损失 = 防守兵力 × (0.2 ~ 0.5)
- **防守方兵力归零**：城池被自动占领

### 城池防御系数
```
标准城池：1.2
仙山福地：1.0
天关要塞：1.8
洞天秘境：0.8
圣地灵脉：1.5
```

## 3.5 胜利条件

| 胜利方式 | 条件 |
|----------|------|
| **完全征服** | 占领地图上所有城池 |
| **圣地净化** | 占领 6 大区域的全部圣地灵脉并坚持 3 回合 |
| **势力覆灭** | 所有敌对势力的城池数为 0 |

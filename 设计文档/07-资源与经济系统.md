# 七、资源与经济系统

## 7.1 资源类型

| 资源 | 图标 | 用途 | 获取方式 |
|------|------|------|----------|
| **灵脉** | 🜁 | 招募兵种、施放法术、建造设施 | 城池每回合产出 |
| **功德** | ☯ | 升级法术、解锁法宝、触发特殊事件 | 攻占城池、击败 AI |
| **道行** | ⬆ | 玩家等级提升、解锁高级策略 | 累计占领回合数 |

## 7.2 灵脉产出公式

```
单城每回合灵脉产出 = 基础产出 × (1 + 灵脉等级 × 0.5) × 区域加成
```

**基础产出：** 10 灵脉/回合
**灵脉等级加成：** 每级 +50%
**区域加成：**
| 区域 | 加成 |
|------|------|
| 洞天秘境 | +30% |
| 昆仑神域 | +20% |
| 东海仙域 | +10% |
| 青城道域 | +10% |
| 天阙圣域 | +25% |
| 幽冥鬼域 | -10%（但兵力恢复 +20%）|

**示例：** 青城山（灵脉 Lv.3，青城道域）
```
产出 = 10 × (1 + 3 × 0.5) × 1.1 = 10 × 2.5 × 1.1 = 27.5 ≈ 28 灵脉/回合
```

| Lv.8 | 2500 | 产出 +350% |

| Lv.10 | 5000 | 产出 +450%，解锁终极兵种 |

|---------|------|

## 7.5 经济策略

### 早期策略（前 10 回合）
- 集中资源升级 1~2 座核心城池的灵脉
- 优先招募道士/黄巾力士，保持兵力均衡
- 积累功德解锁关键法术

### 中期策略（10~25 回合）
- 多线路扩张，占领新城池扩大灵脉产出
- 升级边界城池防御
- 解锁高级兵种和法宝

### 后期策略（25+ 回合）
- 全面升级灵脉至 Lv.7+
- 招募精锐兵种（天兵、特殊兵种）
- 使用终极法术进行决战

# 八、AI 对手系统

## 8.1 AI 设计理念

AI 对手是单人游戏体验的核心。每个 AI 势力具有独特的 **性格特质** 和 **策略倾向**，让玩家面对不同的挑战。

## 8.2 AI 势力详设

### 碧游宫 — "截教铁骑"
| 属性 | 内容 |
|------|------|
| **性格** | 激进好战，优先扩张 |
| **策略倾向** | 前期疯狂扩张，优先攻击弱邻 |
| **兵力偏好** | 偏好高攻击力兵种（妖灵战士、巨兽先锋） |
| **法术偏好** | 攻击类法术优先，三昧真火使用频繁 |
| **弱点** | 扩张过快导致后方空虚，容易被反推 |
| **AI 难度系数** | ★★★★☆ |

**AI 行为逻辑：**
1. 每回合优先评估可进攻目标（选择兵力最少的相邻敌方城池）
2. 如果兵力充足（≥2倍于目标），必定发动进攻
3. 每占领 3 座城池后，暂停扩张 1 回合进行兵力整补
4. 被攻击后倾向全力反扑

### 西方教 — "佛门东渡"
| 属性 | 内容 |
|------|------|
| **性格** | 稳扎稳打，防守反击 |
| **策略倾向** | 优先巩固已占领区域，再缓慢推进 |
| **兵力偏好** | 高防御兵种（金刚护法、天龙众） |
| **法术偏好** | 金光咒、回春术等防御法术 |
| **弱点** | 推进速度慢，容易在前期被压制 |
| **AI 难度系数** | ★★★☆☆ |

**AI 行为逻辑：**
1. 优先升级已有城池的灵脉等级
2. 仅在有 1.5 倍兵力优势时才主动进攻
3. 每个区域至少留 30% 兵力防守
4. 被攻击后会集中 3 座最近城池的兵力反攻

### 妖神盟 — "九尾诡谋"
| 属性 | 内容 |
|------|------|
| **性格** | 诡变多端，游击骚扰 |
| **策略倾向** | 突袭弱侧城池，扰乱玩家部署 |
| **兵力偏好** | 高机动兵种（灵狐刺客、麒麟卫） |
| **法术偏好** | 瞒天过海、缩地成寸等策略法术 |
| **弱点** | 正面决战能力弱，城池防御薄弱 |
| **AI 难度系数** | ★★★★☆ |

**AI 行为逻辑：**
1. 专攻玩家防守最薄弱的城池
2. 经常使用缩地成寸进行跨区域突袭
3. 不打消耗战，小规模突袭后迅速撤回
4. 会故意示弱诱敌深入，然后包围反击

### 散仙盟 — "中立霸主"
| 属性 | 内容 |
|------|------|
| **性格** | 厚积薄发，坐收渔利 |
| **策略倾向** | 前期低调发育，中后期全面爆发 |
| **兵力偏好** | 均衡发展，全面型兵种 |
| **法术偏好** | 辅助类、经济类法术 |
| **弱点** | 前期兵力不足，容易被欺负 |
| **AI 难度系数** | ★★★★☆（后期★★★★★） |

**AI 行为逻辑：**
1. 前 15 回合专注发展和防守，几乎不主动进攻
2. 灵脉等级比其他 AI 平均高 2 级
3. 当有其他两方交战时，会趁机偷袭弱势方
4. 后期拥有碾压性兵力，是所有 AI 中最难对付的

## 8.3 AI 公共逻辑

所有 AI 共享以下行为逻辑：

### 战略评估
- 每回合评估全局态势，计算各势力的城池数、总兵力量
- 当某一势力过于强大时，AI 之间有概率 **结盟对抗**（仅限对付玩家时）
- 当 AI 只剩下 1 座城池时，进入 **困兽之斗** 模式（爆兵+全力反扑）

### 难度调节
| 难度 | AI 加成 | 说明 |
|------|---------|------|
| **简单** | AI 灵脉产出 -30%，无特殊战术 | 适合新手 |
| **普通** | AI 无加成，基础战术 | 标准体验 |
| **困难** | AI 灵脉产出 +30%，使用高级战术 | 有挑战性 |
| **宗师** | AI 灵脉产出 +50%，全战术，结盟概率翻倍 | 极限挑战 |

## 8.4 AI 对话与事件

AI 势力会在特定时刻发送消息，增加沉浸感：

- 初次遭遇时：**"此山是我开，此树是我栽！"**（碧游宫）
- 玩家连胜时：**"道友修为不俗，可愿入我门下？"**（西方教）
- AI 被攻击时：**"大胆！敢犯我疆界！"**（妖神盟）
- AI 覆灭时：**"天道轮回…终有此劫…"**（散仙盟）

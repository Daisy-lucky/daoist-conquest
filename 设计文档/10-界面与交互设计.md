# 十、界面与交互设计

## 10.1 视觉风格

### 美术风格
- **整体风格**：水墨丹青 + 道教元素，融合传统国画与现代扁平化设计
- **色调**：主色调为 **玄黄**（黑金），辅以 **青、赤、白、玄** 四色
- **字体**：标题使用书法字体（如颜体/行楷），正文使用宋体/黑体

### UI 配色方案

| 用途 | 色值 |
|------|------|
| 主背景色 | #1a1a2e（深空蓝） |
| 面板底色 | rgba(0, 0, 0, 0.75) |
| 金色（强调） | #d4a34a |
| 青色（灵气） | #4ecdc4 |
| 红色（敌军） | #e74c3c |
| 绿色（友军） | #2ecc71 |
| 白色（文字） | #f5f5f5 |

## 10.3 交互流程

### 基本操作

| 操作 | 方式 |
|------|------|
| **查看城池** | 点击地图上的城池节点 |
| **选中己方城池** | 左键单击 |
| **调兵** | 选中己方城池 → 点击"调兵" → 选择目标城池 → 拖动滑块设置数量 |
| **进攻** | 选中己方城池 → 点击"进攻" → 点击相邻敌方城池 → 确认 |
| **使用法术** | 点击底部法术图标 → 选择目标 → 确认 |
| **装备法宝** | 打开法宝面板 → 拖拽到城池/势力栏 |
| **结束回合** | 点击底部"结束回合"按钮 |
| **查看全局** | 滚轮缩放，拖拽移动视角 |
| **查看历史** | 点击"战报"图标查看上回合详情 |

### 反馈与提示

| 场景 | 反馈 |
|------|------|
| 选中己方城池 | 城池高亮 + 关联路线发光 |
| 可进攻目标 | 目标城池闪烁红色 |
| 不可进攻目标 | 灰色不可点击 |
| 战斗开始 | 太极光圈特效 + 数字跳动 |
| 法术释放 | 对应法术特效动画 |
| 回合结束 | 转场动画，"回合结束"文字特效 |

## 10.4 音效设计

| 场景 | 音效风格 |
|------|----------|
| 背景音乐 | 古琴、笛箫为主的国风轻音乐 |
| 调兵 | 清脆的拨弦声 |
| 进攻 | 战鼓声 + 剑鸣 |
| 法术 | 对应元素特效音（雷声、风声、水声） |
| 占领城池 | 钟声 + 号角 |
| AI 回合 | 轻缓的竹笛过场 |
| 胜利 | 恢弘的交响国乐 |
| 失败 | 低沉的钟鸣 |

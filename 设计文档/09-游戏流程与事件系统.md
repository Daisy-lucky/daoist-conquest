# 九、游戏流程与事件系统

## 9.1 游戏整体流程

```
启动游戏 → 主菜单 → 新游戏
  ├─ 选择难度（简单/普通/困难/宗师）
  ├─ 选择角色（性别、道号）
  ├─ 选择初始区域（影响开局策略）
  └─ 开始游戏
       │
       ▼
  第一幕 · 浊世初起（1~15回合）
       │  • 新手教程
       │  • 占据 3 座城池
       │  • 首次遭遇 AI
       │
       ▼
  第二幕 · 群雄逐鹿（16~50回合）
       │  • 地图全部解锁
       │  • 各势力全面交战
       │  • 特殊事件触发
       │
       ▼
  第三幕 · 定鼎三界（50+回合）
       │  • 最终决战
       │  • 净化中央灵脉
       │
       ▼
  结局（根据条件触发不同结局）
       │
       ▼
  结算界面 → 返回主菜单
```

## 9.2 随机事件系统

每 5 回合触发一次随机事件，丰富游戏体验。

### 良性事件

| 事件名称 | 触发条件 | 效果 |
|----------|----------|------|
| **仙鹤报喜** | 任意 | 随机一座己方城池 +5 兵力 |
| **灵脉喷涌** | 任意 | 指定城池灵脉等级 +1（不消耗资源） |
| **仙人指路** | 功德 ≥ 50 | 解锁一个随机法术 |
| **天降甘露** | 任意 | 所有城池恢复 20% 兵力 |
| **神兽归顺** | 占领 5+ 城池 | 获得一个强力临时兵种（持续 5 回合） |
| **悟道顿悟** | 任意 | 功德 +30 |

### 恶性事件

| 事件名称 | 触发条件 | 效果 |
|----------|----------|------|
| **浊气爆发** | 任意 | 随机一座己方城池被污染，产出归零 3 回合 |
| **妖兽暴动** | 任意 | 随机一座己方城池损失 8 兵力 |
| **瘟疫蔓延** | 任意 | 某区域内所有城池兵力 -30% |
| **内奸叛变** | 城池数 ≥ 8 | 随机一座城池转为中立 |
| **天劫降临** | 功德 < 10 | 玩家所有法术冷却 +2 回合 |

### 战略事件

| 事件名称 | 触发条件 | 效果 |
|----------|----------|------|
| **秘境开启** | 第二幕 | 出现可争夺的秘境，占领者获得强力法宝 |
| **势力结盟** | 任意 AI 势力 ≤ 3 城 | AI 之间结盟，共同对抗玩家 |
| **中立势力加入** | 第二幕 | 中立城池出现，玩家和 AI 可争夺 |
| **仙魔大战** | 第三幕 | 天兵天将与妖魔开战，波及多个城池 |
| **灵脉崩溃** | 第三幕 | 所有城池灵脉产出减半，持续 5 回合 |

## 9.3 新手教程

### 引导流程

| 步骤 | 教学内容 | 奖励 |
|------|----------|------|
| 1 | 移动视角、查看城池信息 | 50 灵脉 |
| 2 | 调兵操作 | 道士 ×3 |
| 3 | 攻城操作 | 五雷正法（临时） |
| 4 | 使用法术 | 功德 +10 |
| 5 | 结束回合、观察 AI 行动 | — |
| 6 | 升级灵脉 | 灵脉等级 +1（免费） |
| 7 | 招募兵种 | 仙兵 ×5 |
| 8 | 完成教程 | 轩辕剑（法宝，永久） |

## 9.4 结算与成就系统

### 结算评分

| 评分项 | 计算方式 |
|--------|----------|
| **回合评分** | 使用回合越少，分数越高 |
| **征服评分** | 直接攻占的城池数量 |
| **战斗评分** | 胜率 × 战斗次数 |
| **探索评分** | 访问过的城池数量 |
| **总分** | 上述四项加权求和 |

### 成就系统（部分示例）

| 成就名称 | 达成条件 |
|----------|----------|
| **初出茅庐** | 完成第一幕 |
| **百战百胜** | 连续 10 场战斗全胜 |
| **不战而屈** | 使用崆峒印招安 3 座城池 |
| **道法无边** | 解锁全部法术 |
| **法宝收集者** | 收集全部法宝 |
| **横扫六合** | 30 回合内统一三界 |
| **绝地反击** | 只剩 1 座城池时反败为胜 |
| **宗师境界** | 在宗师难度下通关 |
